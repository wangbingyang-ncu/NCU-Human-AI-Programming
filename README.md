## 🧪 Week05 · 单摆物理模拟器（当前实验）

**作品**：[`index.html`](index.html) —— 单文件交互式单摆模拟器，双击即可运行。

- 纯原生 HTML5 Canvas，零外部依赖；RK4 数值积分，45° 大摆角下周期与理论精确值误差仅 0.006%
- 画布下方参数控制台：摆长 / 重力 / 阻尼滑块即时生效，"重置摆动"按钮精准复位到 45°
- 验收测试：30 项自动化检查全部通过，真实浏览器实测 60 fps、控制台 0 报错
- **进阶挑战 ✅**：内置「切换双摆」模式——完整双摆拉格朗日方程 + RK4（能量漂移 2×10⁻⁵%）、第二摆球半透明彩虹渐变拖尾、鼠标可直接拖拽任一摆球释放；混沌特性经数值验证（初值差 1e-4 rad，30 秒后轨迹分离 9.6 rad）

### 人机协同三反思

#### 1. 意图设计思考

编写初始 Prompt 时，我特意限制"单文件不依赖外部库"，避免了 CDN 加载失败问题，确保双击就能跑通 MVP。同时我主动发现了参数中的量纲矛盾——L=200px 是像素、g=9.8 是米/秒²，直接代公式会得到 28 秒一个来回的"慢动作"，最终采用"100px = 1 米"的比例尺方案解决。意图定义不只是"我要什么"，还包括替 AI 划定单位、量纲与验收边界。

#### 2. 报错自愈思考

本次实验控制台最终 0 报错，但开发中出现了三次"无报错信息、结果却不对"的隐性错误，比显式报错更难排查：`git commit --amend` 默认保留原作者导致署名未更新（加 `--reset-author` 解决）；Edge 无头模式虚拟时间不推进 rAF 导致计时器恒为 0（改用 CDP 连真实浏览器验证，2.5 秒真实时间 = 计时器 2.50 s）；低清截图误读为"能量不守恒"（放大核对后确认守恒精确到 0.001 J）。我的修复路径是先用客观证据定位，再决定改什么——而不是看到结果不对就让 AI 盲改。

#### 3. 人机协同哲学反思

AI 承担了约 90% 的代码产出（770 行单文件 + 四层自动化验证），但三件事不可替代：**物理建模决策**（像素与米的换算、阻尼量程"忠实实现还是放宽"取决于作品想表达什么）；**验收标准的定义**（周期误差 < 0.01%、能量漂移 < 10⁻⁸ 这些可证伪指标由我锚定）；**对结果的最终仲裁**（AI 一度把能量误读当真问题报告，是我放大截图核对后判定为误报）。AI 是高效的执行者与验证器，而我是意图源头、证据仲裁者和最终把关人。

## 📖 术语速查（零基础友好版）

| 术语 | 一句话解释 |
| :--- | :--- |
| **仓库（Repository）** | 一个被 Git 全程存档的文件夹。像游戏的「存档点集合」，随时能回到任何一个历史版本。 |
| **`.gitignore`** | 一张「免打扰名单」。名单里的文件（如密码、缓存、大文件）Git 会假装看不见，绝不上传。 |
| **Commit** | 一次「存档」。把当前所有改动打包并写一句说明，永久记录在时间线上。 |
| **Push** | 把本地的存档上传到 GitHub 云端，让别人也能看到。 |
| **README.md** | 仓库的「门面」和「说明书」，打开仓库第一眼看到的内容。 |

## 🔐 安全提醒

- 任何**密钥、密码、Token**一律写进 `.env` 文件，而 `.env` 已在 `.gitignore` 名单中，不会被上传。
- 上传前可用 `git status` 再看一眼：确认没有敏感文件出现在待提交列表里。
- 一旦密钥曾经被提交过，即使后来删除，Git 历史里仍然保留——此时应立即到平台**吊销并重新生成**该密钥。
